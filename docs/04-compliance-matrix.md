## 4.3 What "configuration, not constants" means in code

All the items above that carry a number or a date live in `packages/tax-uae/src/config/*.ts` as **effective-dated rule sets**. For example:

```ts
{ key: 'vat.standard_rate', value: '0.05', effectiveFrom: '2018-01-01', source: 'FDL 8/2017 Art. 3', verify: false }
{ key: 'einvoice.golive.large', value: '2027-01-01', effectiveFrom: '2025-09-01', source: 'MD 244/2025', verify: true }
```

The engines look up values by transaction date, so a rule change is a data migration plus a review sign-off, not a code change. Any value marked `verify: true` shows a warning badge in the admin UI until a compliance owner confirms it.
